# Muse · 个人智能 Agent

会记住你，并帮你把事情办下去的个人 AI Agent。

## 一个日常场景

你收到一封约时间的邮件。Muse 将这封信与已授权的项目记忆联系起来，了解约定的偏好，查看目标日历，提出安排。你确认后，它通过本地宿主写入系统日历，并再次读取核对。后来对方回复要求改期，Muse 会关联原事项，修改原事件，再草拟回复。邮件发送另行确认，手写稿也可直接使用。

## 面向谁

面向需要处理日常邮件、项目约定与个人安排的 macOS 用户，适配“智能日常”的作品表达。赛道名称与最终报名资格仍以主办方表单为准。

## 为什么是 Agent

Muse 记录当前讨论与长期记忆的关系，用任务状态承接后续行动。新对话是新的注意力焦点，相关全局记忆仍可按账号、项目与归属检索；记忆冲突保留并询问，用户可更正或遗忘。

## 技术实现

Muse 使用 OctoScript / Splash 与 Makepad，运行在 OctoSense Agent Runtime 上。云端模型经 `model.complete` 理解语义、生成候选与草拟回复；本地端处理记忆、校验、权限、确认、执行、回读与恢复。模型文本不能当作系统执行成功。

## 当前完成度

现有核心具备邮件、全局记忆、真实日历、确认、恢复和防重复路径。历史版本已完成同一事项的真实邮件与日历闭环；rc51 另有真实模型、内部存储读回、Shell 重启与跨聊天检索证据。本次只增加比赛包装，完整同一最终候选的外部闭环实录仍待补齐，详见 [限制](KNOWN_LIMITATIONS.md) 与 [交付核对](ACCEPTANCE.md)。
