# 本地榜单借鉴与本轮取舍

读取：2026-10-06 本地榜单及五份逐项报告。榜单为固定源码及既有报告的静态评审，不是主办方评分；未在本轮实测竞品。Muse rc45+未提交修补91分/第1，CFAW90分；1分差不能称断崖领先。

- CFAW：输入版本、过期提案拒绝、持久动作状态与恢复对账。Muse已有Goal/Run/版本/来源/载荷守卫，本轮验证导航回调守卫、独立删除后的精确缓存移除。
- Invoice：模型只产候选，真实字段和最终产物由确定性代码独立核对。保留独立get、存储readback和未知发送保护，交付测试不依赖本机未跟踪资料。
- OnCue：区分原文事实、假设和草稿，紧凑交付与接管入口。实录发现标为资料的文字改变任务类型，rc47限制操作判断到明确资料/原文分隔符之前，资料仍完整送入模型。
- BuWei：提交、受理、到达分别记录；批准绑定账号/目标/载荷/版本。保留独立确认，不把SMTP受理当收件到达。

本轮优先级：真实缺陷与失败记录 → 官方边界和真实隐私说明 → 自动模型配置与500MB以内交付 → 真实视频/中文配音/封面 → GitHub同步。

仅采用报告中的工程原则，未读取或复制竞品实现。未恢复长期Goal、周期任务或新Agent Runtime。排名不改变原二十项验收，最终外部全链、第二strong和接收机等仍按实际证据记录。
