# Muse rc51 本轮真实窗口演示

96 秒，1920×1080，H.264/AAC；Tingting 离线中文配音、烧录字幕及独立 SRT。封面由现有官方 icon.svg 几何与原生字体排版制作，附可编辑 SVG。开发候选，产品整体验收仍为 **PARTIAL**。

可发送文件：`Muse-rc51-demo.zh-CN.mp4`、`Muse-rc51-cover.png`、`Muse-rc51-cover.svg`、`Muse-rc51.zh-CN.srt`，独立音轨为 `Muse-rc51-narration.m4a`。文件字节数和 SHA256 以 `SHA256SUMS.txt`、`DELIVERY.json` 为准。不要将 `.local-state/` 临时目录当作交付物。

视频是低帧率真实窗口采集的剪辑，输出 30fps 通过重复已采集画面形成；没有补绘应用内容、插帧、快放或慢放。连续段保持捕获清单中的 monotonic 请求起始时间间隔。22 秒段内一次抓帧失败，已保留 2.1841 秒采集间隙中的上一画面。PNG concat 时间量化及 30fps 重采样存在帧级舍入；不能用于毫秒级动作耗时测量。所有镜头选择、原始帧 SHA、裁剪、整块遮挡区域和停留时长见 `edit-provenance.json`。原始录像清单含约 420 秒结束标记，录制脚本有 420 秒自动停止机制，因此无需伪造 STOP 文件。

左侧历史聊天、桌面和窗口外内容全部裁掉；旧邮件/地址（包括右上“查看来信”）整块不透明遮挡；跨聊天截图只保留中间召回正文。原始私密帧未提交，未混用 UI fixture 画面、旧 rc49 视频或旧跨版本业务成功画面。

v1 的真实 M3 调用及一次用户批准来自 Root 本轮执行记录；录像节选只显示待批准及批准后截图，不宣称录到首版完整点击链。v2 的模型建议/完成状态与 Goal v2 执行记录已核对。Shell 重启的七文件一致、8 提醒、9 Goal、13 Run、17 Action 未变来自独立核对报告 `RC51_REAL_RESTART.json`；这是 Shell 重启而非系统重启，截图前后不伪装连续重启录像。独立报告绑定见 `evidence-binding.json`。

“未核事实”是用户资料摘录的标签；保存动作已独立读回核对。不能把该标签解释为保存动作未核验，也不能把两条说明升级为外部事实核实。冷启动 7/10、重开 5/5 与 GPT 缺有效 API 沿用 Root 本轮交接；本媒体任务没有重测模型或产品，没有新增邮件/日历写入。整体 PARTIAL，非正式上架、非原版20项全 PASS。

## 检查与复现

37 张准备画面全部检查，成片各章节关键帧另行查看；完整视频解码、音轨解码/峰值、13 句实测音频时长与字幕区间均检查。字幕以整句实测音频时段显示，无虚构逐字对齐。TTS 语音未做听感审听或识别回转，不能宣称人工听审通过。详情见 `QA.json` 和 `decode-audio-qa.txt`。

脚本仅使用现有 Pillow、旧媒体目录已安装的 ffmpeg 7.1、macOS say/Tingting/PingFang。未安装新依赖、未开 native 窗口、未访问驱动/网络/模型、未发信。只读私密原图并输出脱敏画面；中间文件 gitignore。空的新输出目录可依次运行 `python3 build_rc51.py prepare`、`narrate`、`render`、`qa`。重复执行前需自行保留旧结果并清理本脚本中间输出，ffmpeg 使用 `-n` 防止覆盖。最终人工/模型视觉 QA 状态不由脚本自动宣告。
