# Muse 使用教程 · RC22

适用于 Intel Mac 的 Muse 0.4.0-rc22 配套应用。实际测试结果见 CURRENT_STATE.md。

## 打开

将完整目录放在可写位置，双击 Muse.app。第一次运行会在应用旁建立空白 Muse Data 文件夹；账号和旧聊天不会随包带入。首次在应用中心找到 Muse，点击 Install，再点击 Open。

本机开发目录的「打开 Muse.command」可沿用你原来登录的资料；面向新用户的 Muse.app 本身没有写入这条资料路径。不要同时运行两份 Muse。

## 日历：一句话就够

1. 点击左侧「日历」。
2. 输入：明天下午三点开项目评审会，地点线上会议。
3. 点击「处理日程」，等待显示已保存的事项和时间。

只写开始时间时，默认持续一小时；地点可以不写。例如「明天晚上八点吃饭」会保存为「吃饭」。这里使用配套 OctoSense 的内置 Calendar。

改期：保持当前事项，在同一个输入框写「改到明天下午四点」，再点「处理日程」。Muse 会修改原日程，保留原事项和未更改的时长。

删除：在保存结果下点击「删除这项日程」。查询：点击「查询今天」，或输入「查询明天的日程」再处理。

第一次调用时，如宿主显示工具权限选项，按自己的意愿确认。若选择允许后原操作未继续，再点击一次处理；以保存结果为准。

## 邮箱：连续发信与日历联动

点击「邮箱」→「添加邮箱」，填写完整邮箱地址及该邮箱服务的第三方客户端授权码。已添加的账号可以点击地址切换，或选择「移除此邮箱」。

发信：选择账号 →「写新邮件」→填写收件人、主题和正文→「发送邮件」→检查后点击「确认发送这封新邮件」。发下一封时点击「写新邮件」，不必退出账号。

收信：点击「同步」，在来信下点击「读取正文」。需要回复可点「回复」；要安排日程，点击正文旁的「添加到日历」。检查提取出的安排并处理，保存后可点「写确认邮件」，检查收件人、内容和时间，再决定发送。

如果时间改变，先在日历改期，再生成对应新安排的确认邮件。旧安排的草稿会失效，避免发送过时内容。邮件显示提交成功后，如需确认送达，可在收件箱同步核对。

## 记忆与项目

点击「记忆」→「＋ 添加」，输入主题和内容，点击「保存到全局记忆」。项目留空表示全局偏好；项目资料应填写对应项目和归属。

修改：在记录下点击「更正 / 遗忘」，填写新内容后点「保存更正」。删除：点击「遗忘…」并确认。切换项目使用工作台上方「切换」；相关记忆按当前项目与归属筛选。

新建对话会保留记忆。普通聊天直接输入问题；也可使用「记住：我的偏好=评审会议默认安排在下午三点」保存明确偏好。

## 行动链与继续处理

右侧行动链显示当前事项、保存结果和下一步。新时间会更新同一事项的计划版本；点击「详情」可查看来源和执行记录。切换事项时先核对右侧标题，正常退出后重新打开可继续查看已保存的记录。

## 遇到问题

窗口最大化时，底部 Dock 保留独立空间；页面内容较长时在页面内部滚动。邮箱正文和写邮件都可以滚动查看。

首次空白包没有云端模型账号，可先用内置基础离线模型；更强模型在 OctoSense 的模型设置中连接自己的服务。邮箱收发需要自己的邮箱账号。

如果显示应用已运行，先切回现有窗口；要切换到另一资料目录，正常退出后再打开。请不要删除 Muse Data 来解决错误，它包含自己的资料。
