# Muse 隐私说明

更新日期：2026-10-06。适用于 Muse 0.3.26-rc46 及其配套 OctoSense 本地扩展宿主。本文件描述工程行为，不宣称已经获得官方审核或法律合规认证。

## 处理哪些信息

当你使用相应功能时，Muse 会处理你输入的对话、任务和计划，任务批准及动作状态、结果与验证记录；启用记忆时还会处理记忆内容、来源引用、摘录、关系、范围标识和更正/遗忘记录。连接邮箱后，宿主提供已授权账号的邮件列表与正文、发件人/收件人、主题、时间和用于追踪的邮件标识。使用日历功能时，会处理已授权系统日历的标识及事件标题、时间、备注、版本和动作结果。未连接或未授权的功能不因此获得可用权限。

Muse 的记忆不是自动收集整台电脑所有文件。当前应用的数据范围由应用存储、用户提供的输入和已经授权的宿主服务决定。

## 本机存储与恢复

应用在其独立存储目录中保存聊天、任务、活动、记忆、设置和结果等数据，使用 JSON 文件与用于恢复和读回核验的记录。宿主的账号资料、模型配置及系统服务数据有自己的存储位置；应用存储不等于系统邮箱或系统日历。存储目录的具体位置随运行包和 profile 而变，不应把某台开发电脑的绝对路径当作所有用户的路径。

本机保存不等于磁盘加密、安全擦除或不会进入系统备份。本候选没有据此承诺端到端加密或所有历史副本的物理删除。

## 账号凭据与模型调用

邮箱授权码、模型 API Key 等敏感配置由宿主的独立配置界面/服务托管，应用 bundle 不应收集、保存或展示这些凭据。请仅在正确的宿主配置界面输入，不要放入聊天、任务 DSL、截图或问题反馈。

Muse 通过宿主的 `model.complete` 请求处理输入，并可能附上与当前任务有关的已授权邮件、日程或记忆上下文。模型服务根据你配置的提供商运行，可能在本机，也可能把这些输入发送到远程提供商；使用宿主模型服务不表示所有推理均在本地。远程模型的保存期限、使用条款和数据处理方式以相应提供商及你的配置为准。关闭记忆或删除本机记录不能撤回已发送给提供商的请求。

## 邮箱、日历与卡片

邮箱连接和收发会与邮箱服务通信。回复草稿与实际发送是不同步骤，发送前应审阅收件人、主题和正文并确认。发送受理不代表对方已收到或已读，需要单独核验。

日历能力来自本候选的本地 EventKit 宿主扩展，尚不属于上游普通 App Hub 应用的获准能力。系统权限、所选日历和外部动作确认均可能限制执行。系统日历及邮箱账号可能按其自身设置同步到远端；Muse 的本机数据不能替代这些服务的隐私政策。

结果和提醒卡片可能显示任务或邮件/日历摘要。请考虑共享屏幕、录屏、桌面卡片等场景中的可见性；发布演示材料前自行去除真实个人信息。

## 更正、遗忘与删除的边界

记忆支持更正、遗忘与停止使用。已实现的遗忘流程会处理本应用对应记忆记录、来源引用及指定恢复快照，并写入提交/读回记录以避免重启重新使用；失败或损坏时可能停止读写并保留待核验状态。更正不等于删除所有历史材料，关闭记忆不等于清空数据。

删除一段对话或遗忘一条记忆，不承诺同时删除邮件服务器上的原件、收件人已收到的邮件、系统日历事件、远程模型提供商记录、另行导出的日志/截图、系统备份或他人副本。日历事件删除是单独批准的外部动作，需核验系统读回结果。外部数据的删除须使用对应服务或应用的独立流程。

## 分发与反馈

候选分发包不包含开发者的邮箱账号、生产 profile、授权码或模型 Key；新安装须由使用者自行配置宿主。这个说明不代表所有分发文件已经获得独立安全审计。请以对应版本的包清单和验证报告为准。

支持入口：[Muse Issues](https://github.com/9tuore/muse-agent/issues)。公开反馈请只提供版本、错误类别和已去除个人信息的复现步骤，不要公开 Key、授权码、账号令牌、真实邮件正文或完整个人数据库。是否公开问题内容由提交者自行判断。
