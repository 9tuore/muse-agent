# 官方SDK与Muse本地差异

原vendor共12000个条目，基础部分来自五个锁定官方commit。现在保留76个普通修改/新增文件，以及锁中的4个相对链接，新增/修改合计80个条目；另有21个原快照未包含的上游条目按原样排除。全树SHA256覆盖文件内容、执行模式和链接目标。

`dependencies.lock.json`记录来源、commit、差异和最终树哈希。`scripts/bootstrap_sdk.py`下载固定官方归档，应用本目录可读源码，恢复相对链接，核对整个SDK树后才放到vendor。已有vendor时只核验，不覆盖。需要离线准备时可提供`--archive-dir`，放置`makepad.tar.gz`等精确commit归档（也接受对应`.tar`）；任何最终内容差异都会失败。

- makepad：35个差异文件，20个排除；保留可信模块、分帧源码准备、文本输入、存储等完整已有框架栈。
- octosense：36个差异条目（32文件+4链接），1个排除；保留模型尝试边界、Mail单线程队列、中文登录、EventKit和运行打包。
- app-hub：9个差异文件；保留Calendar本地准入与标准许可证文本。
- octoscript / octoscript-makepad：与固定上游完全一致，零本地差异。

本地扩展未被声明为官方上游已接纳。许可证仍沿用对应来源。原完整vendor基线保存在Git的be552c1e提交及本机隔离备份；失败证据没有移除。首次恢复依赖需要网络，完整Git历史大小未通过重写缩小。
