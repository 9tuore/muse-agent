# 自主工作入口

Status: OPEN

无需用户填写目标或允许文件。没有更具体的新请求时，新 AI 读 [README.md](README.md) 与 [CURRENT_STATE.md](CURRENT_STATE.md)，自己选择一个影响最大的非核心缺口，直接开始改进。选择时优先能在本机安全复现、能从最终成品验证、能明显推进真实用户体验或比赛验收的事项。

当前推荐起点：修正测试或子进程向签名 `.app` 内写 Python 缓存的问题，确保安装与运行前后验签不被破坏。这是构建/测试范围；用户若给出更新的优先目标，以新目标为准。

非核心文件可以按实际需要修改；核心清单及其他边界见 [AGENTS.md](AGENTS.md)。不要求先写计划或找用户确认普通实现细节。遇到必须改核心、扩大权限、真实付费或真实联系人外发的分支，保留证据并请用户决定，同时可继续其他不受阻的非核心工作。

完成标准：真实现象已复现；改动与原因对应；相关测试及成品前后状态已验证；`CURRENT_STATE.md` 已更新；交接和 Git commit 已完成。未通过的项目明确写 `PARTIAL` 或 `BLOCKED`。
